# eSIM Installation and Activation Guide

## 1. Prerequisites
- Carrier-unlocked device with eSIM hardware support (iPhone XS or newer, Samsung Galaxy S20+, Pixel 4+).
- Stable Wi-Fi connection during initial profile download.
- Authenticated customer profile with an active mobile line.

## 2. Setup Process
1. **Requesting the eSIM Profile**:
   - Access the customer portal or SupportGenie mobile tab and generate a new eSIM activation request.
   - An activation QR code and alphanumeric activation code are provided securely.
2. **Device Scanning Steps**:
   - **iOS**: Settings > Cellular / Mobile Service > Add eSIM > Use QR Code.
   - **Android**: Settings > Network & Internet > SIMs > Add SIM > Download your SIM instead.
3. **Missing or Expired QR Code**:
   - QR codes expire after 24 hours for security.
   - If expired or failed, request customer verification (SMS code or account PIN) to re-issue a fresh activation profile.
4. **Escalation**:
   - If device displays "eSIM Not Supported" on a locked carrier handset, escalate to Device Support for network unlocking verification.
